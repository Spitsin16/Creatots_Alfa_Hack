# src/ui — общие примитивы экранов

Экраны импортируют примитивы отсюда; меняя примитив, проверьте все экраны, где он используется.
Живая витрина всех примитивов: **http://localhost:5173/dev/ui** (только dev-сборка, нужен вход любым пользователем).

```tsx
import { PageHeader, Card, Money, StatusTag, KeyValue, Stack, Grid, LoadingState, ErrorState, EmptyState, Bell } from '../ui'
```

## Каркас экрана

Оболочка (`layout/AppShell.tsx`) уже даёт фон, поля (32px, на телефоне 16px), ширину контента до 1160px, отступ снизу под ассистента и `ErrorBoundary` вокруг страницы. Экран — это просто стек блоков:

```tsx
export function ApplicationsPage() {
  const list = useMyApplications(business.id)
  return <Stack>
    <PageHeader eyebrow={business.name} title="Мои заявки" subtitle="Статус обновляется сам." actions={<Bell />} />
    {list.isPending && <LoadingState view="skeleton" rows={4} label="Загружаем заявки…" />}
    {list.error && <ErrorState error={list.error} onRetry={() => list.refetch()} />}
    {list.data?.items.length === 0 && <EmptyState title="Заявок пока нет" text="Рассчитайте предложение — заявка оформляется в один клик." action={…} />}
    {list.data && <Card title="Все заявки">…</Card>}
  </Stack>
}
```

- Глобальных классов экранов больше нет (старый `styles.css` удалён): всё оформление — в CSS-модулях рядом с файлом и в примитивах `src/ui`. Свои поля/ширину страницы не задавайте.
- У **каждого запроса** три состояния: загрузка (`LoadingState`), ошибка (`ErrorState` с `onRetry`), пусто (`EmptyState`). Белых экранов быть не должно.

## Примитивы — когда что брать

| Компонент | Когда | Главное |
| --- | --- | --- |
| `PageHeader` | шапка каждого экрана | `eyebrow` (бизнес / «Кабинет банка») **или** `back={{ to, label }}` для вложенных экранов; `title` (h1), `subtitle`, `actions` справа (обычно `<Bell />`) |
| `Card` | любая секция экрана | `title`, `subtitle`, `actions`; `view`: `default` белая, `muted` серая подложка внутри белой, `outlined` с рамкой, `dark` тёмная «герой»-карточка (не больше одной на экран); `padding` none/s/m/l; `to` — вся карточка ссылка |
| `Money` | любая сумма | `kopecks` (как из API) **или** `rubles` (прогноз, советы). `size`: inherit / s / m / l (главная сумма карточки) / xl (одна главная сумма экрана); `tone`, `prefix="до"`, `weight`. Строкой — `formatMoney({ kopecks })` |
| `StatusTag` | статус заявки | `status="MANUAL_REVIEW"` → «Проверяет специалист», цвет по смыслу: зелёный — готово, оранжевый — ждём клиента, синий — банк работает, красный — отказ, серый — неактивно. `statusColor(status)` — тот же цвет для своих элементов |
| `ScoreBadge` | **только банк** | `cls`, `score`, `status`; `size="s"` пилюля в таблице, `m` покрупнее, `l` блок в карточке. Клиенту баллы/классы не показываем никогда |
| `KeyValue` | условия, реквизиты | `view="rows"` — «название слева, значение справа»; `view="tiles"` + `columns` — плитки «Сумма / Ставка / Срок». `hint` под значением («расчётно», «примерно»). `null`/`false` в `items` пропускаются |
| `Stack` | вертикальный ритм экрана | `gap` 8–32 (по умолчанию 20 — между карточками) |
| `Grid` | колонки карточек | `columns={2|3|4}` или шаблон `'minmax(0,1fr) 360px'`; ниже 900px складывается в 1 колонку (3–4 колонки — сначала в 2) |
| `LoadingState` | идёт загрузка | `view`: `block` (белый блок вместо карточки), `inline` (в строку внутри карточки), `page` (по центру экрана), `skeleton` (`rows` полос — списки, таблицы) |
| `ErrorState` | запрос упал | `error` (Error/строка), `onRetry` → кнопка «Повторить», `title` |
| `EmptyState` | пусто | `icon` (MIcon из icons-glyph), `title`, `text` — что делать дальше, `action`; `compact` — внутри карточки |
| `ErrorBoundary` | рискованный виджет (график) | страница уже обёрнута оболочкой; внутри экрана — `<ErrorBoundary compact>…</ErrorBoundary>` |
| `Spinner`, `Processing` | индикатор в кнопке / автообработка заявки | `Spinner({ label, light, size })` — API прежний; в кнопках кита лучше `loading` у `Button` |
| `Bell` | колокольчик уведомлений | кладите в `actions` шапки на корневых экранах раздела |

## Кит и правила вёрстки

- Импорт кита **по компоненту**: `import { Button } from '@alfalab/core-components/button/esm'`. Иконки: `import { BellMIcon } from '@alfalab/icons-glyph/BellMIcon'`. Пропсы сверяйте с `.d.ts` в `node_modules/@alfalab/core-components-<name>/esm/`.
- **Одна accent-кнопка на экран**: красная `Button view="accent"` — только главное действие («Оформить заявку», «Подписать»). Остальные — `secondary` (серая), `primary` (тёмная), `transparent`/`text`, ссылки. Красный цвет — ещё только для ошибок.
- Размер кнопок задавайте явно (по умолчанию у кита 56): `48` — главная/крупная, `40` — в карточках, `32` — в таблицах и плотных списках.
- `Typography.Title` — всегда с `font="system"` (иначе кит включает вариант «Styrene» с весом 500 и заголовок выглядит тонким).
- Кит переключает многие компоненты на мобильную версию ниже 1024px (`breakpoint`) — это нормально.
- Подводные камни: `Input` кита не пробрасывает `aria-label` (используйте `label` или скрытый `<label htmlFor>`); `Spinner` кита рисуется только с `visible`; `Tooltip` кита на мобильном превращается в шторку по клику — для кликабельной цели берите `TooltipDesktop` из `tooltip/esm/desktop`; кнопки в `Plate` кит принудительно делает размером 32.
- Стили — **CSS-модули рядом с файлом** (`HomePage.module.css`). Глобальный только `styles/base.css` (токены и базовые стили) — его не правим без нужды.

## Токены

Палитра кита — `--color-light-*` (полный список: `node_modules/@alfalab/core-components-vars/colors-bluetint.css`), отступы — `--gap-*`, радиусы — `--border-radius-*`. Короткие имена приложения (`styles/base.css`) — берите их в первую очередь:

| Токен | Что |
| --- | --- |
| `--app-bg` / `--app-surface` / `--app-surface-muted` / `--app-surface-dark` | фон страницы #f2f3f5 / карточка #fff / подложка внутри карточки / тёмный блок |
| `--app-border`, `--app-border-strong` | разделители и рамки |
| `--app-text`, `--app-text-secondary`, `--app-text-tertiary` | текст |
| `--app-accent` | красный Альфы (главное действие, ошибки) |
| `--app-positive`, `--app-attention`, `--app-negative`, `--app-link` | смысловые цвета текста |
| `--app-radius-card` 24 / `--app-radius-block` 16 / `--app-radius-control` 12 | скругления |
| `--app-card-padding` 28 (`--app-card-padding-mobile` 20) | поля карточки |
| `--app-shadow-card`, `--app-shadow-float` | тени карточки и плавающих панелей |
| `--app-font`, `--app-font-mono` | системный шрифт (фирменные не бандлим; переменные шрифтов кита переопределены на него) |

## Брейкпоинты

- **1280px — главный экран жюри**: никакой горизонтальной прокрутки. Контент при 1280 ≈ 960px (сайдбар 256 + поля 32×2).
- **≤ 900px** — сайдбар превращается в верхнюю панель (60px) с меню-бургером; `Grid` складывается в колонку; планируйте свои сетки так же.
- **≤ 600px** — мобильные размеры: шапка 26px, поля карточек 20px, ассистент — круглая кнопка.
- **375px** — минимальная проверка: ничего не вылезает за экран (таблицы → карточки-строки или `overflow-x: auto` внутри карточки).

## Плавающие элементы и слои

| Что | Где | Слой |
| --- | --- | --- |
| Сайдбар / верхняя панель | слева / сверху | `--z-shell` 20 |
| Ассистент (только клиент) | правый нижний угол, отступ `--app-fab-offset` 24px; окно 400px шириной | `--z-assistant` 40 |
| Демо-панель (`src/demo/DemoPanel.tsx`) | плавающая карточка справа, ширина `--app-demo-panel-width` 360px; ярлык — **на правом краю по центру высоты**, на телефоне — пилюля слева внизу (справа внизу ассистент). Пока открыто окно ассистента (на `<body>` стоит `data-assistant-open`), ярлык и панель скрыты. Скрытую панель возвращают Alt+Shift+D, `?demo` в адресе или «Вернуть» в уведомлении. После «Войти как …» панель сама сворачивается, когда участник попал на свой шаг | `--z-demo` 45 |
| Поповеры и тултипы кита (колокольчик) | у своей кнопки | 50 |
| Модальные окна кита | по центру | 100 |
| Тосты кита | — | 1000 |

- Контент оставляет снизу `--app-fab-safe-bottom` (96px), чтобы кнопка ассистента не закрывала последнюю кнопку экрана. Не ставьте свои `position: fixed` элементы в правый нижний угол.
- Демо-панель монтируется оболочкой на всех экранах кабинета (`<DemoPanel />` в `AppShell`); экран входа — вне оболочки.
